THỰC NGHIỆM CÓ THỂ TÁI LẬP

Từ dữ liệu đến bằng chứng

QASPER → fine-tune E5 → đánh giá retrieval → đưa checkpoint vào hệ thống.

01 / DATASET

Chuẩn bị QASPER

Giữ nguyên train, validation, test theo bài báo; dùng đoạn chứng cứ làm nhãn.

python scripts/download_dataset.pypython scripts/prepare_dataset.py
02 / FINE-TUNE

Huấn luyện trên Kaggle

GPU T4, E5 nhỏ, loss MNRL. Tải checkpoint đầy đủ về máy để chạy CPU.

notebooks/kaggle_finetune.ipynb

Hướng dẫn: docs/TRAINING.md

03 / EVALUATE

Đánh giá trước–sau

Recall, MRR, nDCG và độ trễ truy xuất. Nhập JSON kết quả thật bên dưới.

python scripts/evaluate_retrieval.py --help

Kết quả benchmark

Đánh giá retrieval ở cấp đoạn; độc lập với độ đúng của báo cáo.

Chưa có kết quả thực nghiệm

Nhập file do evaluate_retrieval.py tạo để xem so sánh. Không có số liệu mô phỏng.

CẤU HÌNH HỆ THỐNG / SETTINGS

Cài đặt

Quản lý mô hình suy luận, chuyển đổi chế độ phần cứng và tối ưu hóa hệ thống.

Cấu hình Từng Agent (Per-Agent Execution Mode)

Tùy chỉnh linh hoạt từng tác tử: Chạy qua Cloud API hoặc Chạy Model trên Kaggle GPU

Thiết lập nhanh:
01
Agent 1: Retrieval & Router

Điều phối truy vấn, phân tích đa chiều và tìm kiếm lai C-Speed FTS5 + BM25

Đang dùng: Gemini API (Decomposition)
02
Agent 2: Reader (Layout Parser)

Đọc cấu trúc văn bản PDF, nhận diện bảng biểu và chia khối đa cột

Đang dùng: PyMuPDF & Gemini Guardrail
03
Agent 3: Summarizer (Generator & Critic)

Tổng hợp câu trả lời khoa học, trích xuất nhận định nguyên tử và lọc ảo giác

Đang dùng: Gemini API (Generator & Critic)
04
Agent 4: Fact-Checker & Verifier

Đối soát số học, kiểm chứng ngày tháng và thẩm định NLI SciFact nghiêm ngặt

Đang dùng: Gemini NLI & Numeric Verifier
05
Agent 5: Writer (Academic Report)

Biên tập báo cáo khoa học chuẩn IMRaD kèm trích dẫn nguồn APA minh bạch

Đang dùng: Gemini API (Academic Synthesis)

Đang kết nối RA

Mô hình chính (Primary Model): gemini-3.5-flash
Mô hình dự phòng (Fallback Model): gemini-3.5-flash-lite
Máy chủ Local CPU (Ollama / Llama.cpp trên máy tính) Đang kiểm tra...
Chạy mô hình lượng tử hóa trực tiếp trên CPU laptop/máy tính cá nhân (hỗ trợ Ollama, Llama.cpp hoặc LM Studio) hoàn toàn offline.
Đường hầm Kaggle Worker (Cloudflare Tunnel) Đang kiểm tra...
Mỗi lần bật phiên Kaggle mới, Cloudflare Tunnel sẽ cấp 1 URL mới. Bạn chỉ cần dán URL vào ô trên và bấm "Lưu & Tự động ghi vào .env". Hệ thống sẽ cập nhật cả bộ nhớ RAM lẫn file .env tức thì mà không cần khởi động lại server.

HẠ TẦNG NGHIÊN CỨU

Cấu hình mô hình & định tuyến

Ma trận định tuyến tác tử

Mô hình và phương thức thực thi cho từng bước nghiên cứu.

Mô hình được cấu hình ở backend. API key được giữ trên máy chủ và không gửi về giao diện.

Dùng Gemini

RA_LLM_PROVIDER=gemini
RA_GEMINI_API_KEY=your-key
RA_LLM_MODEL=gemini-3.5-flash-lite
RA_WORKFLOW_PROFILE=balanced

Dùng mô hình cục bộ

RA_LLM_PROVIDER=ollama
RA_LLM_MODEL=qwen3:8b

Thêm semantic retrieval

RA_EMBEDDING_PROVIDER=sentence-transformers
RA_EMBEDDING_MODEL=intfloat/multilingual-e5-small

Cài extra local-models, sửa .env, khởi động lại backend rồi Reindex nếu đã có tài liệu.
